// git init - инициализация локального репозитория
// git mod init <имя модуля> - инициализация Go-модуля для создания файла go.mod для управления зависимостями
// go build - сборка готового приложения с компиляцией кода и созданием в текущей папке готового исполняемого файла ("бинарника") со всеми включёнными зависимостями
// go run main.go - запуск файла main.go (главного файла проекта)
// git checkout main - переход в главную ветку
// git pull origin main - сбор актуальной версии главной ветки на удалённом репозитории
// git checkout -b <тип/имя-ветки> - создание новой ветки и переход в неё
// git status - вывод перечня изменённых, но не добавленных для коммита файлов
// git add . - добавление изменённых файлов для коммита
// git commit -m "<Краткое описание коммита>" - коммит (фиксация изменений в виде определённого состояния проекта)
// git push --set-upstream origin <имя_твоей_текущей_ветки> - пуш (отправка коммита на удалённый репозиторий), если ветка новая и ранее не отправлялась на репозиторий
// git push - пуш, если ветка не новая
// git log - вывод в консоли истории успешных коммитов в текущей ветке
// git reflog - вывод в консоли истории всех Git-изменений в данном проекте (в виде перечня хэшей)
// выход из git log и git reflog - q в консоли
// git show <хэш события> - просмотр кода на этапе того или иного события
